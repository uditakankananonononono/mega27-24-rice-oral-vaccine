# MucoRice 19A accession scope: genomic, not antigen lot measurements

The [2024 19A paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC10978600/) links DRX362635 and SAMD00491847 when discussing whole-genome resequencing for genomic integration location. The live [ENA run report](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=DRX362635&result=read_run&fields=run_accession%2Cexperiment_accession%2Csample_accession%2Cstudy_accession%2Clibrary_strategy%2Clibrary_source%2Cfastq_bytes&format=tsv) resolves those to one run DRR376734, study PRJDB13597, WGS/GENOMIC, with two compressed paired-end FASTQ payloads advertised at 6,845,336,213 and 6,851,439,344 bytes. The [DDBJ BioSample](https://ddbj.nig.ac.jp/resource/biosample/SAMD00491847) and [secondary SeqOut index](https://seqout.org/s/SAMD00491847) describe a 19A leaf/seedling sample, not three seed antigen-expression lot replicates.

The script and test archive and check the original article's accession paragraph against the ENA row, pinning both source hashes. This matters for source selection: the article's three-lot CTB protein-content summary cannot be rebuilt from this one genome run, and a WGS read from leaf tissue cannot directly measure seed-protein dose, gastrointestinal retention or clinical outcome. We fetched *metadata only*, not either FASTQ payload; no accession dataset has been individually fetched-and-used for the locked gate. This does not rule out unpublished lot measurements or other deposited proteomics; it simply prevents a wrong assay from being counted as a validation cohort. No new service, derivation, page, benchmark or discovery credit.
