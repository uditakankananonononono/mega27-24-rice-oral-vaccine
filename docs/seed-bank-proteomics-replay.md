# Seed-bank supplement replay, 2026-09-27

The [original MucoRice 51A seed-bank study](https://pmc.ncbi.nlm.nih.gov/articles/PMC7814724/) supplies [Additional file 3 through Europe PMC](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC7814724/supplementaryFiles). The archived 21-page PDF `12864_2020_7355_MOESM3_ESM.pdf` lists 477 proteins detected in both banks, with aggregated protein-level peptide-spectrum-match (PSM) counts. The scripted layout-text replay checks all 477 numbered rows exactly once and their displayed NSB/MSB ratios to 0.00051. PDF text extraction returns rows 368–391 after 392–460, so the script checks the set of row numbers rather than assuming display order. It does not read individual seed-level measurements.

On those shared-protein rows, the raw PSM Pearson R² is 0.981503, close to the article's reported 0.982; log(1+PSM) R² is 0.852051, showing scale sensitivity. The NSB/MSB ratio of summed PSM is 0.947654, while the median per-row ratio is 1.0. Fifty rows have an NSB/MSB ratio below 0.5 and 38 above 2. These are transparent descriptive results, not independent biology, a new discovery or a vaccine-potency comparison. Selection of shared proteins excludes bank-unique detections; protein-level PSMs do not identify antigen dose, protection, digestion or storage behavior. Supplementary PDF, SHA-256, replay script, JSON and a hermetic test are in this repo. No accession-record, service, derivation or paper-page gate credit claimed.
