# Dose-provenance guard, first prototype, 2026-09-28

The proposed invention is a typed, source-scoped calculator that separates a **printed nominal antigen dose** from any inferred bulk-lot concentration, individual measured exposure and post-digestion survival. It permits multiplying a powder mass and concentration only when study, line, material, cohort/lot and stage agree. Missing lot identity blocks the inference, rather than yielding a confident but false point estimate. On six openly predeclared rice CTB regression cases, it permits one within-source 2007 calculation (50 mg x 1.5 µg/mg = 75 µg), blocks three cross-study/line/material transfers, blocks one unlinked 2024 lot-mean-to-mouse transfer, and retains one human 3 g/6 mg **source-printed** content without claiming individual exposure. A naive multiply-any-available-ratio reference emits numbers for five of these cases, including four that are not supportable as matched-dose estimates. The prototype records these refusals and leaves intestinal and individual doses unknown.

Sources: [2007 rice mouse](https://pmc.ncbi.nlm.nih.gov/articles/PMC1904174/), [2024 line 19A](https://pmc.ncbi.nlm.nih.gov/articles/PMC10978600/), [2021 51A seed bank](https://pmc.ncbi.nlm.nih.gov/articles/PMC7814724/) and [phase 1 human trial](https://www.thelancet.com/journals/lanmic/article/PIIS2666-5247%2820%2930196-8/fulltext). These cases were assembled after all source outcomes had been seen. The result is a transparent regression demonstration of refusal logic, **not** an untouched held-out comparator win, a biological discovery, or proof of algorithmic novelty. Evidence graphs, vaccine ontologies and rule-based data validation already exist; a prior-art audit and prospective external tests are needed. The visible rule set is more precise than naive arithmetic for these *constructed* cases but it is not a novel statistical estimator. No construct, sequence or antigen optimization follows. All project gate credit remains zero.
