# Rice microbiome-transfer data-access decision, 2026-09-29

Status: **NO-GO for scoring** until a target feature matrix and paired participant response labels are source-verified. This memo is an accession/endpoint audit, not a new discovery, cohort, preregistration, or outcome analysis. No raw reads were downloaded, and no validation target was inspected.

## Exact question

Could a score fixed entirely using an independent oral cholera vaccine (OCV) metagenome predict an untouched MucoRice-CTB phase-I antibody response? This is a proposed transportability analysis, not a prediction that biological outcomes are interchangeable. Source OSP-specific memory B-cell (MBC) change and target CTB-specific serum antibody fold-change are different endpoints. The 2021 target authors already associated baseline microbial beta diversity with responder status, so the correct comparator must be constructed on the **same 20 target people and response definition** without tuning the transferred features on them. The candidate AUROC >=0.75 and >=0.10 comparator margin came from an external steering consultation and are not an independently locked scientific preregistration; only freeze thresholds after data provenance, labels, comparison and split have been specified, before target outcomes are examined.

## Explicit go / kill decision and fastest bounded next action

1. **Source readiness:** fetch only the *small* Supplementary Data 6 and source-data table through a directly observed publisher link; inspect fields for SRA sample IDs, immune response, age, and permitted feature definitions. Do not fetch 0.11 TB of reads on a source-screening pass. If published score weights are not available, a future source-only derivation needs its own prereg and compute approval.
2. **Target readiness (the critical gate):** identify a primary repository accession or publisher/author-held *de-identified* 20-person feature-and-outcome table, with sample ID joins and access terms. Verify that baseline samples and response labels represent the same people. If found, preregister the source-only feature map, missing-feature handling, target outcome, confounder/dose checks, fixed comparator and confidence interval before touching those outcomes. If unavailable, mark this experiment unevaluable; a target without paired outcomes cannot furnish an AUROC.
3. **Independent validation guard:** compare participant IDs and collection waves of PRJNA742046 vs PRJNA782606. A reused person or merely re-sequenced sample is not a new independent cohort. Do not relabel a 16S-to-shotgun bridge as direct gene-level replication.
4. **Pivot condition:** if target data remain unverified after publisher supplement + primary archive screens, move to a *separately preregistered* rich-open-data rice/plant-production question where train and validation datasets have explicit assay comparability and disjoint sample provenance. NASA GeneLab/OSDR, ENA/SRA, GEO and public metabolomics are candidate catalogs, not themselves matched datasets or positive findings. A fresh candidate must preserve an independently held-out experimental source and a same-task strongest comparator. Keep discovery questions within published-data scope; no construct/antigen optimization.

No benchmark, service/accession-count or manuscript-page gate is earned by this memo. Main's scheduler must approve any later large read download, alignment or modeling run before it launches.
