# MucoRice adjacent-source identity audit (2026-09-26)

This is published-data triage, not evidence of vaccine efficacy, a construct proposal, or a sequence analysis. Archived source bytes and reproducible summary are in `data/sources/` and `results/metabolights_source_audit.json`.

- [MetaboLights MTBLS437](https://www.ebi.ac.uk/metabolights/MTBLS437), linked to the [2017 seed-metabolome paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC5507873/), exposes a [public metabolite-assignment table](https://www.ebi.ac.uk/metabolights/ws/studies/MTBLS437/download?file=m_MTBLS437_seed_metabolome_metabolite_profiling_mass_spectrometry_v2_maf.tsv) and [sample table](https://www.ebi.ac.uk/metabolights/ws/studies/MTBLS437/download?file=s_MTBLS437.txt). The 351 metabolite-feature rows each have entries across 18 sample columns. The 18 column labels exactly match 18 sample names, grouped as MR-CTB51A (4), NPB-HP (5), NPB-PF (4), and MR-RNAi (5). Only 212 rows have a metabolite name other than blank/unknown. Presence of a cell does not establish a measured, numeric abundance; missingness and censoring require a separate audit before statistics. The feature rows share the one MTBLS437 study accession and are not 351 independently accessioned datasets. The record is distinct from the 2021 51A seed-bank comparison and cannot be silently pooled with it.
- [ENA DRP010027 run report](https://www.ebi.ac.uk/ena/portal/api/filereport?accession=DRP010027&result=read_run&fields=run_accession%2Cexperiment_accession%2Csample_accession&format=tsv) maps one line-19A run DRR376734 to experiment DRX362635 and sample SAMD00491847, linked to the [2024 line-19A paper](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2024.1342662/full). Run metadata is not raw reads, and line 19A is not line 51A. No biological result was inferred from it.

Neither source changes the gate tally: 0/40 applied distinct external services, 0/120 independently accessioned fetched-and-used records, 0/10 independently audited derivations, 0 qualifying paper pages, comparator and novelty unproven. This audit is a source-identity safeguard. Next research step is to inspect numeric feature values and platform/normalization methods before any comparison, then prespecify an independent benchmark rather than retrofitting these source tables to a claim.

## Numeric-value integrity screen (2026-09-26)

A follow-up parser in `scripts/audit_metabolights_values.py` scans the archived MAF and writes `results/metabolights_value_audit.json`. All 351 cells in each of 18 sample columns parse as finite positive numbers (6,318 numeric cells); there are no literal missing/zero/negative cells in this particular processed table. This **does not** establish no censoring or detection-limit imputation upstream. Of 351 rows, 139 have an unknown or empty metabolite name, leaving 212 named rows but only 105 distinct name strings overall (including unknown). There are 104 distinct nonempty database identifiers. Repeated names and unknown features make a metabolite-level count smaller than 351; the table remains a single study accession, not 351 independently accessioned studies. Any inferential work must first check the original 2017 methods and transformations and choose a held-out independent study; the current pass is not a new discovery or a project gate. Source URL remains the [MetaboLights public table](https://www.ebi.ac.uk/metabolights/ws/studies/MTBLS437/download?file=m_MTBLS437_seed_metabolome_metabolite_profiling_mass_spectrometry_v2_maf.tsv).
