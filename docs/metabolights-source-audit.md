## Numeric-value integrity screen (2026-09-26)

A follow-up parser in `scripts/audit_metabolights_values.py` scans the archived MAF and writes `results/metabolights_value_audit.json`. All 351 cells in each of 18 sample columns parse as finite positive numbers (6,318 numeric cells); there are no literal missing/zero/negative cells in this particular processed table. This **does not** establish no censoring or detection-limit imputation upstream. Of 351 rows, 139 have an unknown or empty metabolite name, leaving 212 named rows but only 105 distinct name strings overall (including unknown). There are 104 distinct nonempty database identifiers. Repeated names and unknown features make a metabolite-level count smaller than 351; the table remains a single study accession, not 351 independently accessioned studies. Any inferential work must first check the original 2017 methods and transformations and choose a held-out independent study; the current pass is not a new discovery or a project gate. Source URL remains the [MetaboLights public table](https://www.ebi.ac.uk/metabolights/ws/studies/MTBLS437/download?file=m_MTBLS437_seed_metabolome_metabolite_profiling_mass_spectrometry_v2_maf.tsv).

## Original-method check and interpretation limit (2026-09-26)

The [original 2017 Scientific Reports study](https://pmc.ncbi.nlm.nih.gov/articles/PMC5507873/) describes four experimental replicates for MR-CTB51A and NPB-PF and five each for NPB-HP and MR-RNAi, matching the 18 sample labels in the archive. The study describes GC/TOF-MS extraction and processing with MetAlign and AIoutput2, intensity-ratio comparisons to internal standards (testosterone for nonpolar and ribitol for polar fractions), and 351 metabolite-candidate peaks. Thus the table is **processed peak-intensity-ratio data**, not calibrated oral-antigen dose, intestinal survival, clinical protection or plant-to-plant antigen-yield measurements. Study contexts include hydroponic and field-grown Nipponbare; these are not randomized digestion conditions. The metabolite outcome values were already inspected during source triage, so any hypothesis or model designed using this table now is exploratory, not prospectively preregistered. Retain this study for method and feature provenance or transparently exploratory analyses only; seek an untouched, independently held-out study for any future confirmatory claim. The original study also says raw data are in MTBLS437, but this audit fetched only its MAF and sample files, **not** raw spectra.
