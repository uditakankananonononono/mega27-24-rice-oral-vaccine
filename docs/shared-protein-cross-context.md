# Shared accession labels, distinct estimands, 2026-09-28

The [2021 51A seed-bank Table 2](https://pmc.ncbi.nlm.nih.gov/articles/PMC7814724/) and [2024 19A study Table 1](https://pmc.ncbi.nlm.nih.gov/articles/PMC10978600/) each print a selected set of protein accession labels with ratios. Four labels overlap: AAA72362.1, ACA50505.1, Q01881.2 and Q75GX9.1. For two labels, the printed ratios fall on opposite sides of one; for two, both are below one. **The ratios have different denominators:** 2021 NSB/MSB within the 51A seed-bank generations versus 2024 line 19A/WT. A sign comparison is therefore not evidence of contradictory biology, validation, a line trend or causal change. This exact-label crosswalk is a source-context check only. We did not individually fetch protein accession records or raw spectra, and none of the ratios is an antigen-dose or safety measurement. No comparator, discovery or gate credit.
