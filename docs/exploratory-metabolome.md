# Exploratory 51A-versus-parent metabolome contrast (2026-09-26)

This is a *post-outcome exploratory* computation on the [published MTBLS437 processed MAF](https://www.ebi.ac.uk/metabolights/ws/studies/MTBLS437/download?file=m_MTBLS437_seed_metabolome_metabolite_profiling_mass_spectrometry_v2_maf.tsv), associated with the [original 2017 study](https://pmc.ncbi.nlm.nih.gov/articles/PMC5507873/). I examined outcome values before choosing this particular contrast and statistic, so its label enumeration is not a confirmatory test. The script `scripts/exploratory_metabolome_check.py` and result JSON provide exact byte hashes, 212 named feature rows and all nine sample labels: four MR-CTB51A and five hydroponically grown Nipponbare (NPB-HP). For each feature, log intensity ratios are centered and scaled across the nine samples. The average squared difference in standardized group means is 1.7303345663. Enumeration of all C(9,4)=126 partitions puts the observed label split first (1/126). This fraction is descriptive, **not a valid preregistered p-value**: labels may not be exchangeable with biological batch effects, features are correlated and the analysis was chosen after looking at data.

Large exploratory log-ratio differences include 1-Kestose and two separate rows assigned L-Aspartic acid, demonstrating that feature rows are not unique metabolites. These are **not** vaccine potency, digestion protection, or mechanistic findings. A substantive next study would define one metabolite-level de-duplication and normalization protocol before an untouched cohort is opened, then compare an analysis tool with a same-task baseline on that cohort. The original [2017 methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC5507873/) say the values are GC/TOF-MS internal-standard peak-intensity ratios; their relation to oral antigen dose is not established. No project benchmark or novelty gate crosses from this single-study exploratory analysis.

## Judge-inspired exploratory stability probe

After a [ChatGPT critique](https://chatgpt.com/c/6ab7eaa1-d3e4-83e8-812e-54c618c7dd72), `scripts/feature_stability_map.py` computes feature direction consistency across nine leave-one-replicate-out subsamples and raw/log input alternatives. All 212 named rows are evaluated. The observed group assignment has 180 fully direction-stable feature rows, but a biologically meaningless rotated assignment reaches 187/212, so this simple criterion is demonstrably insufficient for a unique signature claim. The control isn't exchangeability-preserving and supplies no p-value; it simply warns that within-cohort consistency alone can be misleading. The tool component and replay test are committed as exploratory work, with external validation and a same-task comparator still missing. No oral-dose or efficacy inference follows.
