# MEGA27-24: rice-oral-vaccine

Part of the MEGA-27 program, item 24 (edible-vaccine / transgenic-environmental space), lane C.

## Scope
Cereal-based oral vaccine (MucoRice-class) evidence synthesis: antigen stability under storage/digestion, expression-level evidence, and accession-level comparative analysis of the published antigen sequences and cereal host proteomes from public databases.
